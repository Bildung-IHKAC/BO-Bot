# BO-Bot

Der BO Bot ist eine Wissensbasis und ein Prompt für einen **Prototypen** eines angepassten Chatbots, der Schülerinnen und Schüler, Lehrerinnen und Lehrer und auch Eltern bei der Berufsorientierung unterstützt. Er ist modular uns soll in möglichst vielen KI Anwendungen laufen.

- Die Ausführung des Promptes ist in Markdown geschrieben
- Die Wissensbasis folgt dem sich gerade etablierenden OKF Standard
- Abgrenzung zu OKF: Es ist als "Flat-Bundle" ausgeführt. Das heißt das Wissen ist nicht in Dateien in Unterordnern kuratiert, sondern in einzelnen Dateien in einem Ordner. Das ist notwendig, weil viele Chatbot Systeme in ihrer Wissensbasis noch keine Unterordner dulden.  


## Vorgehen

1. Das Wissen und den Prompt (und wenn gewünscht das Zusatzwissen zur Markdown und OKF Bundles, nicht zwingend erforderlich) herunterladen https://github.com/Bildung-IHKAC/BO-Bot
2. Ein Projekt in einem Chatbot anlegen
3. Prompt und Wissensbasis an die dafür vorgesehene Stelle hochladen
4. Chatten
5. Optional: Beteiligen, Ergänzen und Verbessern
